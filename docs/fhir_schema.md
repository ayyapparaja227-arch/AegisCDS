# FHIR R4 Clinical Data Schema & Alert Specifications

---

## 1. Overview
AegisCDS adheres to HL7 FHIR (Fast Healthcare Interoperability Resources) Release 4 standards to ensure seamless integration with modern Electronic Health Record systems (Epic on FHIR, Oracle Cerner Millennium, SMART-on-FHIR containers).

---

## 2. Resource Mappings

### 2.1 Patient Resource (`Patient`)
```json
{
  "resourceType": "Patient",
  "id": "PAT-ROBERTS-001",
  "identifier": [
    {
      "system": "urn:oid:hospital:mrn",
      "value": "MRN-884920"
    }
  ],
  "name": [
    {
      "family": "Chen",
      "given": ["Robert"]
    }
  ],
  "gender": "male",
  "birthDate": "1958-04-12",
  "extension": [
    {
      "url": "http://hl7.org/fhir/StructureDefinition/patient-conditions",
      "valueString": "Type 2 Diabetes Mellitus (E11.9), Essential Hypertension (I10), Hyperlipidemia (E78.5)"
    }
  ]
}
```

### 2.2 Observation Resource (`Observation`)
Represents laboratory measurements and vital signs:
```json
{
  "resourceType": "Observation",
  "id": "OBS-EV-1",
  "status": "final",
  "code": {
    "coding": [
      {
        "system": "http://loinc.org",
        "code": "2823-3",
        "display": "Potassium [Moles/volume] in Serum or Plasma"
      }
    ],
    "text": "Serum Potassium"
  },
  "subject": {
    "reference": "Patient/PAT-ELEANOR-002"
  },
  "effectiveDateTime": "2026-09-04T08:00:00Z",
  "valueQuantity": {
    "value": 6.2,
    "unit": "mEq/L",
    "system": "http://unitsofmeasure.org",
    "code": "meq/L"
  },
  "referenceRange": [
    {
      "low": { "value": 3.5, "unit": "mEq/L" },
      "high": { "value": 5.0, "unit": "mEq/L" }
    }
  ],
  "interpretation": [
    {
      "coding": [
        {
          "system": "http://terminology.hl7.org/CodeSystem/v3-ObservationInterpretation",
          "code": "HH",
          "display": "Critically High"
        }
      ]
    }
  ]
}
```

### 2.3 ClinicalAlert Schema
Represents normalized CDS notifications generated by EHR rule engines and processed by AegisCDS:
```json
{
  "id": "ALT-EV-01",
  "patient_id": "PAT-ELEANOR-002",
  "category": "LAB_ABNORMALITY",
  "raw_priority": "CRITICAL",
  "title": "CRITICAL LAB: Serum Potassium 6.2 mEq/L",
  "description": "Serum potassium is 6.2 mEq/L (Critical High >= 6.0 mEq/L). Immediate risk of lethal ventricular arrhythmia and cardiac arrest.",
  "trigger_rule": "BPA_CRIT_LAB_HYPERKALEMIA",
  "timestamp": "2026-09-04T08:15:00Z",
  
  "status": "ACTIVE_CRITICAL",
  "is_critical_safety_bypass": true,
  "actionability_score": 1.0,
  "is_suppressed": false,
  "suppression_reason": null,
  
  "bundle_id": "BUNDLE-CRIT-9f2a1b",
  "guideline_source": "KDIGO 2024 Clinical Practice Guideline for CKD (Rec 1.3.2)",
  "guideline_evidence": "Immediately obtain 12-lead ECG... suspend potassium-sparing diuretics... initiate potassium binder.",
  "suggested_actions": [
    { "action_type": "STAT_ORDER", "order_name": "Stat 12-Lead Electrocardiogram (ECG)", "urgency": "STAT" },
    { "action_type": "STAT_ORDER", "order_name": "Hold Spironolactone and Lisinopril immediately", "urgency": "STAT" },
    { "action_type": "STAT_ORDER", "order_name": "Lokelma (Sodium Zirconium Cyclosilicate) 10g PO TID", "urgency": "URGENT" }
  ]
}
```

### 2.4 CareBundle Schema
Represents consolidated, actionable care packages presented to the clinician:
```json
{
  "id": "BUNDLE-MCC-4b8c91",
  "patient_id": "PAT-ROBERTS-001",
  "title": "MCC Comprehensive Annual Preventive & Monitoring Bundle",
  "priority": "MEDIUM",
  "category_summary": "Consolidated Preventive Care & Annual Screenings",
  "consolidated_alert_ids": ["ALT-RC-04", "ALT-RC-05", "ALT-RC-06"],
  "clinical_rationale": "Joint ADA-KDIGO 2024: Consolidated diabetic preventive exams reduce fragmentation and improve screening adherence.",
  "evidence_citation": "ADA Standards of Care in Diabetes (2024) | KDIGO CKD Consensus",
  "suggested_orders": [
    { "action_type": "LAB_ORDER", "order_name": "Spot Urine Albumin-to-Creatinine Ratio (uACR)", "urgency": "ROUTINE" },
    { "action_type": "REFERRAL", "order_name": "Referral: Diabetic Podiatry & Monofilament Foot Exam", "urgency": "ROUTINE" },
    { "action_type": "IMMUNIZATION", "order_name": "Pneumococcal Conjugate Vaccine (PCV20)", "urgency": "ROUTINE" }
  ],
  "timestamp": "2026-09-04T08:15:30Z",
  "status": "AWAITING_HUMAN_APPROVAL"
}
```
